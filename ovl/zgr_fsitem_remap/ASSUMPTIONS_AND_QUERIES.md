# ZGR_FSITEM_MAP / ZI_GR_FSREMAP_CUBE — Assumptions and Queries

Project OVL (assumed, see item 1) · requirement received in chat on 06/11/2026 with the source of
`I_MatrixConsolidationReportC` as shown in ADT on **OCD 500** · prepared 06/11/2026

Requirement as received: *"we need to create a table which has consolidation unit, fs item and new
fs item. User will maintain that and on top of this view we will create another view which will
give the new fs item in a new col if present else the old fs item should appear in the cds view
in the new fs field also."* The view named is the standard Group Data Analysis cube
`I_MatrixConsolidationReportC` (SQL view `IMCRPTC`, 697 lines, filed as
`original/I_MATRIXCONSOLIDATIONREPORTC.ddls.asddls`).

Each item: the question, where it comes from, what the delivered objects assume if no answer
arrives, and what breaks if that assumption is wrong. Items marked **before activation** are
cheap now and expensive later.
